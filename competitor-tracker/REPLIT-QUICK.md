# ⚡ Replit Quick Start (5 minuten)

## Stap 1️⃣: Download & Upload

```
1. Download: competitor-tracker.zip (je hebt dit al!)
2. Ga naar replit.com
3. Klik "Create" → "Import from File"
4. Upload competitor-tracker.zip
5. Wacht tot unpacked ✓
```

## Stap 2️⃣: API Key Toevoegen

```
1. Klik het 🔑 Secrets icoon (links)
2. Voeg toe:
   
   ANTHROPIC_API_KEY = sk-ant-YOUR_KEY_HERE
   
3. Druk Enter ✓
```

## Stap 3️⃣: RUN!

```
1. Klik de grote "Run" knop
2. Wacht 2-3 minuten
3. Je ziet:
   
   ✅ Check voltooid!
   📊 Dashboard: data/dashboard.html
```

## Stap 4️⃣: Dashboard Bekijken

```
1. In Files (links) → data/ folder
2. Right-click op dashboard.html
3. "Open in new tab"
4. 📊 Jouw dashboard!
```

## 📱 Team Delen?

1. Klik "Share" (rechtsboven)
2. Toggle "Public"
3. Stuur link naar team
4. Iedereen ziet live dashboard

## 🔄 Dagelijks Runnen?

**Optie 1: Handmatig** (Gratis)
- Klik Run elke dag
- Script doet check
- Je ziet results

**Optie 2: Always On** (€10/maand)
- Klik ⭐ → "Always On"
- Repl draait 24/7
- Script runt automatisch om 23:00

**Optie 3: GitHub Actions** (Gratis)
- Push naar GitHub
- GitHub runt dagelijks
- Files sync naar Replit
